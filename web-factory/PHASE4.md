# Phase 4 — ARPAI Web Convergence

## Objective
Converge the ARPAI web portfolio into one controlled architecture without destabilizing `oneilnissan.ai`.

## Canonical structure
- `arpai.co` — corporate parent and public front door
- `oneilnissan.ai` — Tenant 001 runtime; preserve existing production behavior
- `nissanreviews.com` — Nissan authority/community property
- `nissantrades.com` — transactional trade/acquisition property
- `nissandeals.org` — offer/campaign property

## Immediate sequence
1. Freeze the domain registry and redirect policy.
2. Replace the public `arpai.co` surface with the approved Fortune-100 Phase 1 design without moving runtime capabilities into the marketing surface.
3. Launch `nissanreviews.com` as a content/community property using the ARPAI design system.
4. Build `nissantrades.com` and `nissandeals.org` from shared factory primitives.
5. Keep `oneilnissan.ai` isolated as Tenant 001 and only converge reusable core services, not tenant-specific code/data.
6. Route authenticated, stateful, sensitive, real-time, CRM/DMS, or agent-execution capabilities through the canonical Vercel/ARPAI runtime.
7. Apply 301 redirects for defensive ARPAI domains only after DNS/host verification.

## Guardrails
- No destructive DNS changes without explicit validation.
- No fake metrics, ratings, reviews, or customer proof.
- No duplicate canonical content across multiple domains.
- No public exposure of internal control-plane details that do not help a buyer understand the product.
- No claim of completion until production behavior is verified.

## Production gates
- Mobile and desktop review
- Canonical URLs and metadata
- Analytics/event taxonomy
- Redirect validation
- Domain/DNS verification
- Form and lead-routing verification
- Privacy/terms/disclosure pages
- Runtime separation verified
- Production deployment smoke test

## Success condition
The portfolio appears to be one deliberate company with one visual system, one governance model, one deployment logic, and distinct properties matched to distinct customer intent.
